# Awesome-Privacy-Management

## Top Privacy Management Ecosystem



**Curated List of SaaS Products & Open-Source GitHub Projects**  

*Focused on Privacy Management, Data Privacy Operations, Consent Management, Data Subject Rights, Data Mapping, Privacy Risk & Regulatory Compliance*  

**Last updated: August 2026**



This repository tracks notable **SaaS/hosted platforms** and **open-source projects** for **Privacy Management**. These tools help organizations manage privacy programs, consent and preferences, data inventories, data mapping, Records of Processing Activities (RoPA), Data Subject Requests (DSRs), privacy impact assessments, vendor risk, cookie compliance, privacy incidents, regulatory requirements, and privacy governance.



**Examples** include OneTrust, TrustArc, DataGrail, Securiti, Transcend, Osano, BigID, WireWheel, Didomi, and Privado. Modern privacy-management platforms increasingly combine privacy operations with data discovery, automated data mapping, consent orchestration, data-subject-rights automation, and broader data governance. OneTrust, for example, currently positions its platform around privacy automation, consent and preferences, data-use governance, and continuous governance across data and AI.



**Open-source emphasis**: This section is heavily expanded with open-source consent-management platforms, privacy-preserving data infrastructure, GDPR tooling, DSAR components, identity/consent systems, privacy-enhancing technologies, and developer libraries. There are substantially fewer mature open-source replacements for complete enterprise platforms such as OneTrust or TrustArc, so the open-source ecosystem is presented as a set of composable building blocks rather than implying feature-for-feature equivalence.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites or repositories.

## Open-Source GitHub Projects



- **[Klaro!](https://github.com/kiprotect/klaro)**  

  Open-source, privacy-friendly consent management platform for websites. It supports granular consent for third-party applications, multiple consent modes, customization, multilingual interfaces, and GDPR/ePrivacy-oriented workflows.



- **[Microsoft Consent Package](https://github.com/microsoft/Consent-Package)**  

  Open-source developer-focused consent-management platform sample with granular consent, proxy consent, age-specific flows, revocation, auditability, extensibility, storage adapters, REST APIs, and React components.



- **[ConsentStack](https://github.com/ConsentStack/cmp)**  

  Open-source consent management platform designed as a developer-focused and human-centric CMP for managing website consent and privacy preferences.



- **[Profile & Consent Manager (PCM)](https://github.com/Sympol/pcm)**  

  Open-source identity, profile, consent, preference, and segmentation platform designed around privacy-by-design principles. It provides an immutable consent ledger, privacy-oriented data handling, encryption, and modular domain architecture.



- **[Pryv](https://github.com/pryv)**  

  Open-source privacy-oriented personal-data infrastructure providing data sovereignty, consent, access scoping, auditability, and self-hosted data management.



- **[OpenPrivacy](https://github.com/open-privacy)**  

  Open-source privacy and privacy-enhancing-technology ecosystem containing projects aimed at building privacy-preserving applications and infrastructure.



- **[OpenDP](https://github.com/opendp)**  

  Open-source differential-privacy ecosystem for building privacy-preserving statistical analyses and data-release systems.



- **[OpenDP Library](https://github.com/opendp/opendp)**  

  Open-source library implementing differential privacy concepts and mechanisms for privacy-preserving data analysis.



- **[Tumult Analytics](https://github.com/opendp/tumult-analytics)**  

  Open-source differential-privacy analytics framework for performing privacy-preserving analysis on sensitive datasets.



- **[OpenMined](https://github.com/OpenMined)**  

  Open-source ecosystem for privacy-preserving machine learning and computation, including technologies for secure and decentralized data processing.



- **[PySyft](https://github.com/OpenMined/PySyft)**  

  Open-source framework for privacy-preserving data science and machine learning, designed to enable computation while minimizing direct access to sensitive data.



- **[Private Set Intersection / PSI Projects](https://github.com/topics/private-set-intersection)**  

  Open-source ecosystem of cryptographic techniques and implementations enabling organizations to compare datasets without directly exposing the underlying records.



- **[Open Policy Agent](https://github.com/open-policy-agent/opa)**  

  Open-source policy engine useful for implementing programmable authorization and data-use policies within privacy architectures.



- **[Keycloak](https://github.com/keycloak/keycloak)**  

  Open-source identity and access-management platform supporting authentication, authorization, SSO, identity federation, roles, and consent-aware application architectures.



- **[Authentik](https://github.com/goauthentik/authentik)**  

  Open-source identity provider and access platform useful for self-hosted privacy portals, data-subject request systems, and controlled access to personal-data services.



- **[Zitadel](https://github.com/zitadel/zitadel)**  

  Open-source identity and access-management platform supporting organizations, users, authentication, authorization, and identity governance.



- **[Nextcloud](https://github.com/nextcloud/server)**  

  Open-source self-hosted data platform with strong privacy and data-sovereignty characteristics that can serve as infrastructure for privacy-sensitive document and personal-data workflows.



- **[PrivacyIDEA](https://github.com/privacyidea/privacyidea)**  

  Open-source multi-factor authentication and identity-management platform useful for securing privacy-management portals and privileged privacy workflows.



- **[OpenMetadata](https://github.com/open-metadata/OpenMetadata)**  

  Open-source metadata-management and data-catalog platform supporting data discovery, lineage, ownership, classification, and governance. It can provide a foundation for privacy data inventories and mapping.



- **[DataHub](https://github.com/datahub-project/datahub)**  

  Open-source metadata platform for data discovery, lineage, classification, governance, and data ownership that can be extended for privacy inventory and data-mapping workflows.



- **[OpenLineage](https://github.com/OpenLineage/OpenLineage)**  

  Open standard and open-source ecosystem for collecting data lineage information, useful for understanding personal-data flows across systems.



- **[Apache Atlas](https://github.com/apache/atlas)**  

  Open-source metadata and governance platform providing classification, lineage, discovery, and governance capabilities that can be adapted for privacy-data inventories.



- **[Amundsen](https://github.com/amundsen-io/amundsen)**  

  Open-source data discovery and metadata platform useful as a foundation for identifying datasets containing personal or sensitive information.



- **[Trino](https://github.com/trinodb/trino)**  

  Open-source distributed SQL query engine useful for querying privacy-related data across heterogeneous systems while implementing centralized access policies.



- **[Apache Ranger](https://github.com/apache/ranger)**  

  Open-source data security and authorization framework providing centralized policy management and access control across data platforms.



- **[Open Policy Agent](https://github.com/open-policy-agent/opa)**  

  Open-source policy engine for implementing fine-grained policy decisions across applications, APIs, infrastructure, and data services.



- **[Vault](https://github.com/hashicorp/vault)**  

  Open-source secrets-management infrastructure useful for protecting credentials, encryption keys, tokens, and sensitive configuration in privacy-management systems.



- **[Wazuh](https://github.com/wazuh/wazuh)**  

  Open-source security monitoring platform that can complement privacy programs through security monitoring, vulnerability detection, compliance monitoring, and audit capabilities.

**Frameworks for building custom privacy-management systems**: Combine **Klaro! / ConsentStack / Microsoft Consent Package** for consent, **PCM / Pryv** for identity and preference management, **OpenMetadata / DataHub / Apache Atlas** for data inventory, **OpenLineage** for data flows, **Open Policy Agent / Apache Ranger** for policy enforcement, and **Keycloak** for identity and access management.



A potential open-source privacy architecture can look like:



**Data Sources → Data Discovery → Classification → Data Inventory → Data Mapping / Lineage → Privacy Policies → Consent & Preferences → DSR Automation → Risk Assessments → Audit & Analytics**



For consent management:



**Website / App → Consent Banner → Preference Center → Consent Ledger → Policy Engine → Downstream Systems**



For data-subject requests:



**DSR Intake → Identity Verification → Data Discovery → Data Lineage → Search / Export / Delete / Restrict → Human Review → Audit Trail → Secure Response**



For enterprise data governance:



**Data Catalog → Personal-Data Classification → Lineage → Processing Activities → Privacy Risk → Policy Enforcement → Monitoring**



One particularly interesting current open-source project is Microsoft's **Consent Package**, which explicitly provides granular consent, revocation, audit trails, policy management, REST APIs, storage adapters, and React components.



**Klaro!** is another mature open-source option specifically targeting website consent management, with granular consent, customization, multilingual support, and GDPR/ePrivacy-oriented functionality.



The open-source ecosystem is considerably stronger when **privacy management is decomposed into individual capabilities**. Instead of attempting to reproduce a monolithic OneTrust-style platform, developers can combine:



**Consent + Identity + Data Catalog + Lineage + Policy Engine + DSR Workflow + Audit + Privacy Analytics**



This composable approach can provide a self-hosted foundation for organizations that require greater control over privacy infrastructure, data residency, customization, or vendor independence.



## How to Contribute



1. Fork the repo.

2. Add/edit entries in `README.md` (follow existing format).

3. Include: name, link, 1–2 sentence description, and whether it's SaaS or open-source.

4. Prefer projects with active development and publicly accessible source code.

5. For infrastructure projects, clearly identify them as **privacy building blocks** rather than complete privacy-management platforms.

6. Submit PR with a short explanation.



Star the repo if you find it useful!



## Disclaimer



- This is a **community-curated** list — not exhaustive and not an endorsement.

- Privacy-management platforms vary significantly in scope: consent management, DSR automation, data mapping, RoPA, privacy assessments, cookie management, data governance, and regulatory compliance.

- Open-source projects listed here may provide only one component of an enterprise privacy-management platform and may require substantial integration and customization.

- Open-source consent-management or privacy tooling is **not automatically a complete legal-compliance solution**.

- Always verify current licensing terms, project activity, security posture, regulatory coverage, and production readiness before deployment.

- Privacy regulations vary by jurisdiction and continue to evolve. Organizations should obtain appropriate legal and privacy-professional guidance for their specific requirements.

- Personal data should be handled according to applicable privacy, security, retention, access-control, and data-governance requirements.

- Differential privacy, anonymization, pseudonymization, encryption, and other privacy-enhancing technologies do not by themselves guarantee regulatory compliance.
